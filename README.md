# Optimization Techniques - MatLab

Welcome to the **Optimization Techniques - MatLab** repository!
This repository contains MATLAB implementations of various optimization techniques algorithms. It includes solutions and methods used in solving linear programming problems, non-linear optimization, and other advanced topics.

## 📁 Repository Contents

| File                | Description |
|---------------------|-------------|
| `assignment.m`       | Contains solution to the assignment problem solved using hungarian method. |
| `bigM.m`             | Implements the Big-M method for solving LP problems with artificial variables. |
| `duality.m`          | Demonstrates primal-dual relationships in linear programming. |
| `dualSimplex.m`      | Dual Simplex method implementation for LP problems. |
| `fibonacciSearch.m`  | One-dimensional search using the Fibonacci method. |
| `lcm.m`              | Implements the Least Cost Method for transportation problems. |
| `linprog.m`          | MATLAB built-in LP solver usage example. |
| `newtonsMethod.m`    | Newton’s method for unconstrained optimization. |
| `nwcm.m`             | North West Corner Method for transportation problems. |
| `simplex.m`          | Standard simplex method implementation. |
| `Lab Report.pdf`     | Lab report documenting experiments and results. |
